# V66 面向用户的经纬刻度尺

2026-10-24。用户确认 V65 线条不再明显闪烁，并将外侧刻度的要求明确为：左纬度、下经度，位置便于阅读，随着地球旋转更新其地理读数。界面名称统一为“经纬”。

## 操作和显示

Full 的“更多 → 经纬”统一开启球面网格、左侧纬度尺、下侧经度尺及选点功能。捏合拖动继续旋转地球，短按地表显示唯一主要坐标卡，现有城市选择仍复用城市卡。赤道与本初子午线保留较粗网格。旧外弧及地理文字替换为双测量尺，不另建工具栏或定位服务。

每个数字通过短引线指向地球边缘内侧的一个可见位置。该位置的真实纬度或经度就是数字所表达的量；刻度间隔在空间中均匀，并不意味着地理值始终等间隔。任意倾角下也不把弧上的几何角度误标成经纬度。极点经度不唯一时显示破折号。数值为一位小数；主坐标卡仍为两位小数 N/S/E/W。

观察框以地球中心和当前头部位置建立，保持竖直，与地球展示旋转和手动倾角分离。框的位置每帧更新，头部位置用 180 ms 平滑；UV 读数最多每 50 ms 更新一次，不降低地球动画帧率。文字直接成为刻度框的子节点，位移、朝向和缩放共用同一变换。数字使用官方 PICO Text、系统字体，20 sp / 空间缩放 56；坐标卡由 16 sp 调为 17 sp。上述数值均为项目调校参数，不是官方强制规范。

刻度尺在一张静态批次网格内生成，不每帧重建。原地球上普通网格、主网格、选点环各一份，Full 共 4 份网格。接缝仅做绘制曲线补形：日期变更线两侧各 6° 球面桥接，平滑校正中点纬度；不会修改原始贴图、三角形 UV 或选点计算。原 V65 极点处理和抗闪烁线宽保持。

Shared 继续使用相同坐标计算、浮起网格、选点圆环和底部主卡。新双刻度尺仅在 Full 显示；Shared 已移除旧随球外弧，现共 3 份网格。桌面尺寸、原轻量资源、自转和交互不变。
