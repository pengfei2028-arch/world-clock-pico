# 全球气温 V56：零度深蓝与饱和冷暖对比

按用户反馈修改显示配色，V55 提交 4609d4b 和安装包保留可回退。

## 调整原因与结果

V55 在 0°C 附近已使用浅青，15–20°C 色块接近粉彩白；大范围低饱和颜色削弱冷暖对比。V56 将 0–5°C 定为深蓝，5–10°C 为较亮的蓝，10–15°C 为饱和青，15–20°C 为青绿，20–25°C 转黄；25°C 以上继续每 3°C 分档，并逐步转橙、红、深红。低于 0°C 的多个蓝阶继续变深，缺失数据仍独立灰色。

在着色器的 0°C 柔化边界中点，未叠加地形明暗的参考 sRGB 从 56/190/227 变为 15/73/192。该值用于说明配色变化，不是头显颜色测量。

地形的无色明暗系数从 0.5–1.3 收至 0.65–1.0，保留纹理明暗，避免额外提白及高亮通道截断。原 8K 贴图、球体、太阳与世界时间材质均不修改；只调整气温球壳显示。

保留默认 100% 不透明度、半径 1.003、既有色带曲线平滑、25°C 以上 3°C 档、现有图例位置及简洁 UI。真实 GFS 数值、时刻、原始城市查询、UV 与资源管理不变，不能把配色变化描述为冷区真实面积变化。
