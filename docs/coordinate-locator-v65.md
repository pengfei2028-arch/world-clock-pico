# V65 经纬线与标注修正

后续用户手动反馈：线条不再闪烁，但仍有一条折线，文字应再放大；外侧刻度应面向用户固定而非跟随球面旋转。已进入 [V66 双刻度尺](coordinate-rulers-v66.md) 修正。下文为 V65 交付时记录。

2026-10-24。用户体验 V64 后确认拖动不会误选、只出现一张主要坐标卡，同时指出网格应略微离开地表、线条过细且闪烁、极点折线错误、部分文字跟随不自然和字号太小。V65 针对这些反馈修改，不重做交互或地球资产。

## 具体变化

网格半径从 1.009 倍提高到 1.025 倍；按 Shared 默认直径 0.5 米换算，离地表约 6.25 毫米。普通网格宽度从 0.0024 提高到 0.0085，主线从 0.0038 提高到 0.012（模型局部半径约为 2）。刻度和选点环的宽度均为 0.008。Full 城市及坐标引线半径 0.025 → 0.045，Shared 引线 0.35 → 0.7 毫米；卡片内部引线改为 2 dp。

原先的扁平细带在侧视时投影宽度趋近零，容易断续。现改为八边圆截面的合批线条，保持侧视厚度，按朝外绕序绘制并剔除背面，避免透明前后壁叠加。仍为四份批次资源，不为每一段刻度建立独立实体；没有每帧重建网格。线条增厚和抬高旨在改善可读性，最终是否消除明显闪烁仍由模拟器连续画面和头显体验验证。

V64 将 UV 等值线交点排序后直接连接；极区 UV 扇形不规则，形成了不连续的折线。V65 每 1° 取样，经线在纬度 70–75° 平滑过渡到球面弧，并汇聚到原网格 UV 真正共用的南北极顶点。极点顶点相对理想 ±Z 轴有约 0.1° 偏移，现直接从原资产读取。正常区域仍使用原模型 UV，所有点击反查、城市坐标和选点环位置继续使用精确三角形 UV；极区刻线的平滑补形不是对原 UV 数据或地球贴图的修改。

参考文字原先被投射到固定前方平面，现在位置直接取地表 Entity 的地理锚点变换，和参考引线在同一帧更新。只调整朝向使其便于阅读；二维投影仅用于避让，不再控制位置。背面仍渐隐，拥挤时隐藏标签。普通坐标卡与原城市信息继续共用既有卡片布局和避让逻辑。

参考文字使用 18 sp、空间缩放 50；相比模拟器上实际安装过的 V64 初包（12 sp / 23.4），明显提高可读性。坐标卡标题和数字改为 16 sp，数字行高 18 sp，在原卡片内显示两行。界面材质、字体仍沿用官方 UI。

以上参数集中在 `CoordinateStyle`。Shared 的独立边界和底部坐标卡保持，外弧数字标签仍仅在 Full 显示。
