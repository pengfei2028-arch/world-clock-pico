# V75 地震透明材质与批量绘制

用户 2026-10-25 要求降低零散对象/空间 UI 开销，使用贴球面透明材质实现震中和扩散动画。本版不改地球资产、数据目录或批准的 UI 布局。

## 实现

- 圆点与波纹共享一份 PICO ShaderGraph 透明 Unlit 材质。没有波纹图片、图片序列或实时光照；每帧只推进动画参数。Shader Graph 编译 bundle 63,486 字节，0 个纹理采样器。
- 使用局部球面贴片，而不是给每个事件创建独立球体/环对象。所有圆点一个批次、最多三组波纹一个批次、聚合数字一个批次；固定 3 个原生模型实体，详情引线另保留原来的一个。这里只描述应用对象数，不等同于测量到的 GPU draw call 数。
- 球面贴片通过切平面的指数映射生成，UV 半径对应球面角距；表面半径仍为原坐标半径的 1.012 倍，深度测试开、深度写入关、背面剔除。所有对象挂在实际地理表面节点下，随原地球倾角/缩放/动画运动。
- 点每个 8 个三角形；波纹贴片每组 128 个三角形，三道环由同一个材质求值。2.4 秒周期、0.8 秒错开、普通 3.5°/选中 6°范围保持。
- `QuakeStyle` 集中设置时长、间隔、范围、线宽和透明度，初始化时覆盖编译材质参数；没有另一个时间轴。
- 聚合数字取消 8 个原生 AttachmentPanel，使用系统 sans-serif-medium 一次绘制的 528×64 字形图集，约 132 KiB 基础 RGBA 像素（并非实测显存）。字形只生成一次，所有数字共用一份 Unlit 材质/图集和一个网格批次。详情/筛选仍使用唯一的官方 PICO UI 面板。
- 地表点、聚合及波纹所属事件改变时才在后台重建对应批次；动画本身不重建几何。输入/聚合最多每 100 ms 更新，扩散与淡出按场景帧更新。最新请求合并，旧网格延后 3 帧释放；一份当前网格加短暂替换资源，避免每个事件持有资源。
- 每帧只读取四个地理参考点建立仿射变换，再由 CPU 批量转换事件位置，替代逐事件的原生坐标转换调用。
- 整个 Full 场景结束时取消任务并关闭材质、图集、网格及 bundle；切换其他模块隐藏批次、停止波纹参数更新，少量固定句柄留待复用。Shared 仍不创建地震层。
- 修正聚合字形顶点颜色导致文字压黑；共用 Dock 内播放控件改用 Material.None，避免重复玻璃材质。后者的最终显示仍待手动核对。

## 已有验证证据

- 152 项单元测试通过：包含原有 147 项，加上球面角距、极点/日期变更线、朝外绕序/深度间距、2000 余点批量几何、仿射变换与字形图集检查。最终 Dock 材质小改另通过编译。
- 对 APK 内同一编译 MaterialX 图求值，验证周期接缝连续、三组遮罩、选中范围与出现淡入；不是仅检查一份另写的数学公式。0 波纹贴图/采样器和参数契约通过。
- 用户手动运行初版 V75 和白色数字修正版，实际日志确认启动原 8K 地球、创建材质与读取真实 USGS 数据成功；进入 7 天/30 天/24 小时并拖动地球、拖动回放时间。在这两次捕获窗口无 NO_MEMORY、批次失败或致命异常。
- 30 天筛选 1173 个 M4+ 目录事件时，应用模型批次仍是 3；捕获时最多 3566 个地震图层三角形。当前网格稳定为 3，替换/退役时采样见 4–5。地球停住的一段窗口中 meshCommits 不再增加，证明扩散动画不依赖重建网格。
- 已读取截图：原地球及贴球面白点/波纹可见，夜侧仍可见，未发现透过球体的背面光圈。截图不能替代完整多视角遮挡验收。
- 73 项既有 assets 在源码和最终 APK 中字节一致。新增仅小型 QuakeDecals.bundle；系统字形图集在运行时创建。
- 最终 APK 已签名并覆盖安装 emulator-5554；已核对设备 APK SHA256 与交付包相同。最终 Dock 小改后的再次手动运行、播放入口、完整点选/列表/回放，以及 Shared 往返仍待验证。
- 未连接头显；尚无 GPU draw call、GPU 显存、真机帧率/功耗下降比例的测量。保留的 meminfo 只反映进程内存，不能充当显存测量或证明没有长期泄漏。
