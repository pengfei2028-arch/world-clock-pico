# V64 经纬定位

2026-10-24，原生 PICO Spatial SDK 6.1.9 / Kotlin / Compose。基于用户确认的 V63 添加独立辅助图层；未更改原地球材质、贴图、光照、温度数据或开场流程。初包已在模拟器由用户打开，读到了启用图层和旋转时的原生核对日志。之后仅调大外侧文字并同步避让尺寸，生成 r2 包，尚未覆盖安装以免打断用户操作。本版不是已验收稳定版。

## 使用

Full Space 在现有“更多”中点“经纬定位”，整套网格、刻度和定位标注一起开关。气温模式的同一工具菜单也有此入口。没有底部 Dock 或三个独立开关。

开启后，在地球上短按或短暂捏合再松开选择位置，显示两位小数的纬度、经度和 N/S/E/W。拖动沿用原旋转；长按沿用暂停，不选点。新地表选点暂停展示自转和回正 8 秒供阅读，真实 UTC、昼夜计算和夜灯效果时钟继续运行。选择已有城市时显示城市名称，复用该城市原卡片位置，不再另弹第二张坐标卡。

Shared Space 在原有尺寸滑条旁加入小型定位图标，支持同一图层、选点和坐标。为留在 0.9 × 1.05 × 0.9 米容器内，Shared 坐标卡固定在地球下方控制区的空隙，Full 坐标卡优先位于选点右侧。Shared 使用简化外弧，外弧数字及“赤道 / 本初子午线”外侧标签目前仅在 Full 显示。

## 地理参考系

原模型在网格局部坐标中以 +Z 为北极。原有 `GlobeGeography` 的 198° 经度偏移是理想方向近似；原城市铆钉实际上由模型 UV 三角形插值生成。本次定位也使用相同的原始位置和 UV，避免换用理想球公式后与城市和大陆错位。

`tools/export_coordinate_surface.py` 从 `EarthShaderV51.usda` 导出 31,948 个三角形的位置及面角 UV，仅供离线计算，二进制为 1,916,888 字节。Full 与 `DesktopEarthV62.usda` 导出的数据逐字节相同。未复制 SDK 代码或新增地表纹理。

`SpatialPointerInfo.position3D` 为 View 局部坐标，经 `SpatialViewContent.convertPosition(..., ViewCoordinateSpace.Local, surfaceEntity)` 转入真正承载地表网格的 Entity 坐标。这样原生变换链包含展示旋转、地轴倾角、地理旋转、缩放和父节点平移。随后与实际三角形求交，以重心权重还原 UV，再以 `v * 180 - 90`、`u * 360 - 180` 转成经纬度，经度归一化到 [-180, 180)。

原 UV 在接缝与极区并非严格矩形。实际命中读数仍取原三角形；绘制闭合经纬线时，仅对 UV 缺口沿同纬度轮廓做接缝衔接。实际物理极点显示“经度不唯一 · 极点”，不会伪装成稳定的唯一经度。两位小数为显示精度，不是测绘精度承诺；原模型及图像本身的地理配准误差不由本层修正。

接口依据：[PICO Spatial SDK 6.1.9 SpatialPointerInfo](https://developer.picoxr.com/spatial-api/6.1.9/spatialui/foundation/com.pico.spatial.ui.foundation.gesture/-spatial-pointer-info/index.html)，以及本机相同版本 SDK 的 MeshResource、MeshModel、UnlitMaterial 和 Entity 变换接口。

## 渲染与交互

- 主要经纬线每 30° 一条，赤道和 0° 半子午线较亮。线几何沿原 UV 等值轮廓构建，父节点跟随原地表；背面接受原地球深度遮挡。
- 外弧固定在一条地理经线上，纬度 -75° 至 75°、每 5° 一个刻度、30° 主刻度更长。弧所在经度在场景建立时由初始观察方向决定，此后跟随地球旋转。刻度表示真实纬度，不是屏幕角度。
- 小圆环跟随地理点，Full 使用既有城市卡布局、引线和避让算法，边缘/背面平滑隐藏。参考标签拥挤时隐藏；位置以地球和固定初始视点为基准，朝向当前观察者。普通选点只保留一张主要坐标卡。
- UI 使用既有 PICO GlassAction、主题和系统字体；定位图标为简单线稿。关闭时约 250 ms 淡出，选点和标签状态随之清空。
- 复用原地球命中目标和指针所有权；短按 40–1200 ms，原拖动阈值、跟踪异常拒绝规则继续生效，另设原始位置 18 mm 移动否决。UI 点击由原 UI 命中系统处理，不为定位添加全屏或第二套输入监听。
- 四份合批几何：普通网格、主线、局部弧与刻度、选点圆环。无逐帧几何重建。关闭图层后不绘制；保留固定四份资源供重开，退出场景时显式释放。CPU 地理表保存在会话内，两种空间共用。
- 图层加载失败时保留原地球，入口显示加载失败。Shared 不调用 Full 专用 HMD tracking；沿用容器观察象限与 spatial pointer 路径。

可调参数集中在 `CoordinateStyle`，网格局部半径约为 2：

| 参数 | 初始值 |
| --- | --- |
| 地表半径倍数 | 1.009 |
| 普通 / 主线宽 | 0.0024 / 0.0038 |
| 普通 / 主线透明度 | 0.26 / 0.52 |
| 外弧半径倍数 / 线宽 / 透明度 | 1.065 / 0.0028 / 0.42 |
| 圆环半径 / 线宽 | 0.025 / 0.0035 |
| 标签径向偏移倍数 | 1.11 |
| Full 外侧标签字号 / 空间缩放 | 14 sp / 36，与现有城市卡相同的空间缩放 |
| 开关淡变 / 选点阅读时间 | 0.25 秒 / 8 秒 |

这些是初始美术参数，头显中的细线可读性、闪烁、标签间距和指针阈值仍需实际体验。
