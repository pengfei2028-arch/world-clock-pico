# 全球气温 V55：固定温标细分与简化界面

本轮延续原生 Kotlin / Compose / PICO Spatial SDK 6.1.9 工程。V54 提交 37ec2dd 及安装包保留，可回退。

## 视觉与操作

- 固定温度阈值为 −30、−20、−10、0、10、15、20、25、28、31、34、37、40°C。25°C 以上每 3°C 分一档；不按每帧最高、最低值重新配色。
- 低温到温和区采用蓝、青、浅青；20–25°C 为浅黄，25–28°C 为金黄，再逐步转橙、红、深红。通过调整显示配色减少整片橙红的观感，真实温度及其地理范围没有改变。颜色不是冷热健康风险等级。
- 保留独立球壳、1.003 倍半径、数值纹理和既有曲线平滑；默认叠加强度为 100%。气温模式内仍复用原 8K 贴图提取地形细节。
- 温标与时间滑条共用同一个布局，宽度均为 528 dp，左右对齐并随 caption bar 一起移动。温标分段宽度与实际摄氏度区间成比例；两端保留超范围符号和 °C。
- 删除主界面的来源/说明/状态段落和“缺失”图例项。“现在”按钮只保留简短文字。缺失数据本身仍是独立灰色，不填成 0°C。
- 右侧 … 菜单内保留叠加强度调节、数据来源、模型起报/有效/获取时间和更新状态。强度控制默认隐藏，仍可调至 0% 查看原地表。
- 世界时间模式保持原布局与功能。气温模式的整组工具栏下移留出温标空间，避免温标遮挡地球下缘。

## 数据与资源

仍使用 NOAA GFS 2 m 空气温度真实样例，起报 2026-10-22 00Z，有效时间 2026-10-22 07Z 至 2026-10-23 08Z，共 26 帧。海洋显示的仍是近地面空气温度。

数据清单的 legendBreaksC 协议保持原 10°C 主刻度；客户端显示色带与协议独立细分。样例目录 53 个文件逐字节与 V54 相同，城市查询仍采样原始数值网格。原地球、太阳、云层及其他 17 项既有 APK 资源 SHA256 一致，未降低底图质量。
