# V63 Shared 尺寸与自转

2026-10-23，延续原生 PICO Spatial SDK 6.1.9 工程。用户在 V62 头显体验后要求更快自转、默认直径 0.5 米、最大 0.8 米。

## 改动

- Shared 自转由 4.5 改为 9°/秒，40 秒一圈。这是本次项目调校，Full 仍为 3°/秒；共用的手动拨动、暂停、停留及回正逻辑不变，展示自转不推进 UTC。
- 默认直径 0.5 米；官方滑条范围 0.18–0.8 米。会话内切换保留用户调节后的大小。
- 尺寸集中到 `DesktopEarthLayout`，同时用于默认容器、强制窗口约束、SpatialView 深度、模型中心和滑条范围。容器为 0.9×1.05×0.9 米；最大球体侧面/前后留 5 cm，顶面留 7 cm。底部独立 10 cm 控件区和最大地球间隔约 6 cm，控件平面在地球最前缘前 3 cm。控件不随地球缩放。以上为项目布局选择。
- V62 头显日志显示关闭白色底板的运行时更新在 Stage 切换中超时。V63 等已确认 Shared、地球载入和淡入结束，再延迟 250 ms 提交 `VolumeBasePanelType.None`；失败最多重试三次，间隔 500 ms。离开桌面时取消。保留系统 CaptionBar，便于整容器移动。实际底板消失和摆放操作仍待用户确认。
- 材质继续使用 V62 的不透明 Unlit、IBL=0、平滑晨昏、海陆高光、简化云层和夜灯局部噪声，模型名字 `DesktopEarthV62` 为有意保留，并非旧包。
