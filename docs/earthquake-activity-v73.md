# V73 地球活动 · 地震

2026-10-25：用户明确批准 Figma 设计并授权开始工程实现。对应原生 PICO Spatial SDK 6.1.9 / Kotlin / Compose 工程，版本 0.73.0（versionCode 73）。

## 操作

1. 进入 Full Space，点击时钟右侧的地震波形圆按钮。
2. 在右侧面板选择 24 小时 / 7 天 / 30 天，以及 M4+ / M5+ / M7+。默认 7 天、M4+。
3. 轻点地球事件圆点查看详情；数字圆标表示重叠事件，点击后在列表中选择。拖动地球仍为原手势，不会因为拖动反复选点。
4. 现有时间条中的三角按钮播放或暂停，左右拖动会暂停并选择历史时刻；上方“返回总览”恢复整个周期。
5. 关闭详情回到筛选；再次点击地震入口回到进入前的世界时间或气温模块。温度按钮仍可直接切换气温。
6. 最左侧原“＋”替换为批准的 PICO clock 图标，打开的城市二级页面保持原功能。
7. 更多菜单仍可收起到 Shared 桌面地球。地震图层第一版仅在 Full 中绘制；Shared 保持原轻量地球。

## 实现

- 使用原始写实 Earth / Clouds / Sun 资源和昼夜逻辑。73 项已有 assets 与修改前及最终 APK 内内容均逐项 SHA-256 一致。
- 单一 528dp 时间条、原位 Dock：总宽从 720dp 调整为 784dp，左侧为 48dp 时钟、48dp 地震入口；16dp 间距。时间条、温度入口、更多入口、Caption 的空间位置保持。
- 时间条内容按 600ms 交叉淡入淡出；底部原生材质仅一层。界面继续复用 PICO Glass/GlassAction、系统字体及 hover，未采用网页 CSS。
- 地震详情使用一张 368dp 面板，包含地点、震级及类型、发生 UTC 时间、深度 km、经纬度、记录更新时间、事件 ID、数据获取时间。缺失可选字段显示“暂无”。隐藏城市卡与普通选点卡，返回原模块恢复。
- 点击命中沿用原球体碰撞和 CoordinateTap，使用原 Earth UV 离线地理转换。事件放在原地理层级下，缩放、倾角、展示旋转自动继承。
- 球面环以震中法向为轴，用球面小圆的 cos/sin 几何计算中心和半径。半径略高于云层（1.012 倍表面半径），使用 unlit、深度测试，背面不会穿透地球。无相机朝向的雷达贴纸。
- 3 组波纹预算，每组 3 环；单环 2.4s，错开 0.8s，普通最大约 3.5°、选中最大 6°。选中暖色，其余弱白色；换组先淡出再淡入。波纹与真实地震波、震感、受灾范围无关。
- 相邻可见事件按投影距离聚合（24dp 聚合、32dp 解散滞回），代表点仍位于真实震中。最多 32 个数量标签；超过数量标签预算的事件保留原位圆点。不是移动震中“避让”。
- 选中事件或列表停住自动展示与回正，保留手动旋转。背面详情提示“震中已转至背面”，可“查看震中”恢复朝向；细引线仅在前面显示。
- 一轮回放约 60 秒。事件仅在发生时间到达后出现；圆点保留到该周期结束，最近事件的强调约 4.8 秒再用 0.6 秒减弱。暂停冻结回放时间，波纹仍作为位置标记循环。拖动不生成中间事件，松手后保持暂停。回放中的网络修订延迟到返回总览时应用。
- 下载、JSON 校验、去重、缓存读写放在 IO 协程；周期切换取消旧请求，旧周期结果不能覆盖新周期。缓存使用 AtomicFile。退出 Full 时取消相关任务并释放本模块原生资源。
- 波纹复用 1 个环网格和 9 个实体，圆点复用球网格，引线复用柱网格，共 3 个网格资源。退出模块销毁点对象、关闭标签和波纹；3 个小网格留在当前 Full 场景供再次开启复用，场景销毁时释放。每帧不重建几何。密集首次绘制每轮分批最多创建 32 个点，背面未显示点不预先创建。

## 数据来源与边界

[USGS GeoJSON Summary 官方接口说明](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php) 支持 day / week / month，官方说明每分钟更新；本版在地震模块打开时约每分钟检查一次。

使用 2.5_day / 2.5_week / 2.5_month 完整快照后在本地筛选 M4/5/7，未使用只包含 M4.5 以上的接口去假装提供 M4+。纬经顺序按 GeoJSON 的 longitude, latitude, depth 读取。稳定 ID 及 aliases 组成去重集合，最新记录胜出；整份快照替换处理位置、震级修订及移出目录的记录，显式 deleted 记录也处理。

三个时间分别保存：事件 properties.time、记录 properties.updated、应用成功获取时间；周期边界来自目录 metadata.generated，缓存失败时显示实际缓存周期。下载超过 16 MiB、超过 20000 条或记录校验不完整则拒绝替换旧数据，不把截断结果标成完整目录。

[ComCat 目录来源与覆盖](https://earthquake.usgs.gov/data/comcat/) 来自各地监测网络。面板明确写“编目覆盖随地区而异”，不宣称全球所有真实地震都已收录。[USGS 数据使用说明](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits)要求适当署名；应用保留 USGS 署名，不使用其徽标。原始地点文本保留官方返回内容，未增加翻译服务。
